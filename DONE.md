# ScaleMatrix Web — Definition of Done

- [ ] All committed product features have documented acceptance criteria and are satisfied.
- [ ] Authentication/onboarding/session flows are verified against the API contract.
- [ ] Production UI contains no unintended mock/static business data.
- [ ] `npm run lint` passes with zero errors.
- [ ] `npm run build` passes cleanly.
- [ ] Available automated tests pass; where no test harness exists, the limitation is documented and approved before final completion.
- [ ] Primary user flows have loading, empty, error, and success states where applicable.
- [ ] Accessibility basics are met: semantic controls, keyboard operation, focus visibility, labels, and meaningful image text alternatives.
- [ ] Primary layouts are usable on mobile and desktop.
- [ ] No secrets are committed and existing `.env` files remain untouched.
- [ ] README/docs describe setup, environment configuration, build commands, architecture, and relevant API assumptions.
- [ ] TODO has no unresolved P0/P1 product-quality tasks or unapproved blockers.
- [ ] Final full verification is recorded in PROGRESS.md.
